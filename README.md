# CRUD C V1

My first CRUD project developed in C during my Software Engineering degree.

## About the Project

This project is a CRUD (Create, Read, Update, Delete) system for managing people records. Data is stored in a text file, allowing information to persist even after the program is closed.

The application was developed in C using the C99 standard and focuses on file manipulation, data structures, programming logic, and modular programming concepts.

## Features

* Create new person records
* List all registered people
* Update existing records by ID
* Delete records by ID
* Automatic ID generation
* Data persistence using text files

## Stored Information

Each record contains:

* ID
* Full Name
* Date of Birth
* Phone Number

## Technologies

* C (C99)
* GCC Compiler
* File Handling (TXT)

## File Structure

Records are stored in the following format:

id|name|birthDate|phoneNumber

## How to Compile

gcc crud_pessoas_Ellen.c -o crud_pessoas

## How to Run

Linux / macOS:

./crud_pessoas

Windows:

crud_pessoas.exe
